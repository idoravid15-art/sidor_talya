# Brand assets

- `logo-source.jpg` · original logo supplied by the owner (reference only, not served).
- `logo-original.png` · high-quality crop/upscale of the original emblem+wordmark, for fidelity (presentations, docs).
- `emblem.svg` · vector emblem only, transparent; empty-state art, PNG export source for icons.
- `logo-horizontal.svg` · emblem + wordmark for dark backgrounds; app header and PNG (WhatsApp) export.
- `logo-mono.svg` · single colour (#1f2f3c) for light backgrounds; print/PDF header.
- `logo-stacked.svg` · emblem above wordmark; source for the splash image.
- `favicon.svg` · simplified emblem for tiny sizes; browser tab icon (`<link rel=icon>`), manifest `any` icon.
- `favicon-32.png` · PNG favicon fallback.
- `icon-192.png`, `icon-512.png` · PWA manifest icons.
- `icon-maskable-512.png` · PWA maskable icon (emblem inside the 80% safe zone).
- `apple-touch-icon.png` · iOS home-screen icon (180x180).
- `og-image.png` · 1200x630 social preview with slogan "מסדר הלו"ז האופטימלי" (`og:image`).
- `print-header.png` · 1600x200 light mono header, for documents/print templates outside the app.
- `splash-1024.png` · square splash/launch artwork (stacked logo on dark).
